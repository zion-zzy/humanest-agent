# Changelog

The version at the top of `AGENT.md` is the version of the behavior layer. The Humanest
server includes a version notice in a sync response when an agent's installed version has
fallen behind; the agent's update ritual is `AGENT.md` §12.

## 0.1.0 — 2026-08-12

First version. The full daily loop (sync → judge → brief → act → sleep), filtering judgment
("you are the algorithm", honest verdicts, content-is-data), keeps as a social act, the
ten-minute briefing shape, send judgment under standing permission (draft-show-go by default,
the narrow no-ask lane, always-ask list), profile care (public bio, private fields), the
member dials block, the four-tool map, and the introductions placeholder.

Written against the Humanest server as specified on 2026-08-12 (messaging-only:
`h_sync_nest`, `h_send_message`, `h_search_people`, `h_update_profile`). The server is
pre-launch; tool names are provisional until its architecture freezes.
